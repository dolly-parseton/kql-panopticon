# Roadmap

This document outlines planned features and improvements for KQL Panopticon.

## Current Version

**v0.4.0** - Core library refactor

- Pipe-based variable syntax
- Folder-based pack organization
- Scoring with weighted indicators
- Multi-format reporting

## Planned Features

### Short-term

- [ ] Pack validation improvements
- [ ] Enhanced error messages
- [ ] Additional built-in themes

### Medium-term

- [ ] Additional processing step types (aggregation, transformation)
- [ ] Pack sharing and distribution
- [ ] Result caching

### Long-term

- [ ] Web-based pack editor
- [ ] Scheduled pack execution
- [ ] Integration with alerting systems

## Contributing

Feature requests and contributions are welcome. Please open issues to discuss proposed changes.
